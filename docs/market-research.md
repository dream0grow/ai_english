## 2. 언어 습득 효과성 — 검증된 학술 근거

**AI 대화 연습 자체는 효과가 입증되어 있다** (우리 프로젝트의 근거이기도 함):

- 30개 실증 연구 체계적 리뷰(2020–2024): AI 챗봇 사용은 **말하기·쓰기(산출 기능)에서 가장 큰
  향상**을 보임. 효과의 3대 메커니즘 = **실시간 피드백, 발화 불안 감소, 연습 기회 증가**
  [ScienceDirect S2215039025000086]
- 24개 연구 리뷰(2017–2023): 음성 챗봇은 발화 기회를 늘리고 **부담이 낮은 환경**에서 지속적
  대화를 가능하게 함 [ScienceDirect S2666920X24000316]
- 10대 학습자 2주 실험(음성 어시스턴트와 대화): **영어로 말하려는 의지 유의미 상승, 발화 불안
  감소** — 어린 학습자에게 단기간에도 효과 [같은 리뷰]

**반면 개별 앱의 효과 근거는 생각보다 약하다**:

- Duolingo 자체 효능 연구(2024, 4개 영역 시험): A2 과정을 다 끝낸 학습자도 읽기는 중상급인데
  **말하기는 최하 수준** — 앱 학습이 스피킹에서 가장 약함을 자사 연구가 인정
- Duolingo 2021 스피킹 연구: 초급 과정 완료자의 66%(스페인어)/53%(프랑스어)만 A2 스피킹 도달,
  프랑스어 응시자의 약 28%는 채점 불가 수준의 발음
- ELSA의 대표 연구(PLOS ONE 2025, n=205)는 **만족도 조사이지 실력 향상 측정이 아님**.
  흥미로운 결과: "유용하다고 느끼는 것"과 만족도는 상관없었고, **기대 충족(confirmation)이
  만족의 최대 예측 변수** → 앱은 "약속한 것을 그대로 해주는 것"이 중요
- 학계가 지적하는 미해결 과제 2가지: **장기 동기 유지**와 **맥락 인지 개인화 부재**

### 가격 대비 효과성 순위 (조사 종합)

효과성 = 검증된 습득 메커니즘(실시간 피드백·불안 감소·연습량) 충족도 + 리뷰 평가

| 순위 | 앱 | 판단 근거 |
|---|---|---|
| 1 | TalkPal | 최저가에 핵심 메커니즘(대화량) 충족. 단 피드백 얕음 |
| 2 | 스픽 | 한국어 지원 + 구조화 레슨. 가격은 중상 |
| 3 | Langua | 기능 최고 평가지만 최고가. 진지한 성인 학습자용 |
| 4 | ELSA | 발음 한 영역 특화 대비 고가. 최근 "AI 채팅 전환 후 구조 상실" 불만 |
| 5 | Duolingo | 습관 형성엔 최고, 스피킹 효과는 자사 연구로도 최약 |
| — | Buddy.ai | 아동 안전 1위지만 콘텐츠 얕음(문법 없음, 3~8세) |

## 3. 벤치마킹할 기능·UI 요소 (검증된 것만)

1. **교정 표시의 업계 표준 패턴** (5개 앱 공통 확인): 틀린 부분 ~~취소선~~, 고친 부분 **굵게**,
   또는 발화 아래 교정문 병기. Langua·스픽은 메시지 옆 정오 표시 아이콘(✓/✎) 추가.
2. **탭하면 펼쳐지는 문법 설명** (Langua "Explain this feedback"): 교정을 누르면 이유 설명 —
   대화 흐름을 깨지 않으면서 원할 때만 학습 모드로.
3. **복습 시스템이 승부처**: 리뷰어 종합 1위 Langua의 핵심 강점이 단어장+복습 시스템.
   반대로 Praktika는 간격 반복·어휘 추적 부재가 최대 약점으로 지적됨.
4. **AI가 자기 의견을 먼저 내는 대화** (TalkPal의 약점 반면교사): 묻기 전엔 의견을 안 내는
   AI는 대화가 얕아짐 → 우리 프롬프트에 "자기 경험/의견을 먼저 꺼내라" 규칙 반영.
5. **아동 안전 설계** (Buddy.ai 벤치마크): 응답 수위 제한, 부모 잠금(산수 문제 게이트),
   아이 음성 데이터의 외부 비공유 — 우리는 자가 호스팅이라 데이터가 집 밖에 안 나감(구조적 우위).
6. **기대 충족이 만족의 열쇠** (ELSA 연구): 화려한 기능보다 "약속한 동작이 매번 그대로 되는 것".
   MVP에서 기능 수보다 대화 루프의 안정성에 집중할 것.

### UI를 이렇게 만들기 위해 우리가 할 일

- 1·2번 패턴을 MVP 대화 화면에 반영: 말풍선 옆 ✓/✎ 아이콘, 교정 접기 패널(취소선+굵게), 탭하면 한국어 설명
- 디자인 시안이 필요하면: 참고 앱 스크린샷 수집 → 스타일 가이드 1장(색·타이포·컴포넌트) 확정 →
  PWA는 CSS로 구현(외부 디자이너 불필요, 아이도 쓰므로 큰 글자·큰 터치 타깃·밝은 색)
- 게이미피케이션은 최소만: streak(연속 학습일)와 오늘 말한 문장 수. Duolingo식 과도한 보상 구조는
  "pay-to-win, 아동 부적합 콘텐츠" 불만의 원인이므로 배제

## 4. 기존 앱들의 공통 페인포인트 → 우리의 셀링 포인트

### 검증된 페인포인트

| 페인포인트 | 근거 |
|---|---|
| 발음 피드백이 부정확/무의미 | Praktika는 일부러 틀리게 발음해도 "정확" 판정(리뷰 검증됨), TalkPal 발음 점수 부정확, 스픽 9개월 사용기 "발음 교정 효과 미미" |
| 복습·누적 학습 부재 | Praktika 간격 반복 없음, ELSA "AI 채팅 전환 후 구조화 연습 사라짐"(Trustpilot) |
| 대화가 얕음 | TalkPal AI가 의견을 먼저 내지 않아 대화 지속 안 됨 |
| 장기 동기 유지 실패 | 학술 리뷰가 지적한 업계 공통 미해결 과제 |
| 맥락 인지 개인화 부재 | 학술 리뷰 지적 — 학습자의 생활·환경을 아는 대화 불가 |
| 아이-성인 사이의 공백 | 아동 앱(Buddy.ai)은 3~8세용으로 얕고 문법 없음, 성인 앱은 아동 안전 인증 없음(Duolingo도 중학생 이상 권장) — **초등 3~5는 정확히 사각지대** |
| 결제 불만 | ELSA 무료체험 종료 전 결제·해지 어려움 등 |

### 우리 앱의 셀링 포인트 (차별화 순위)

1. **"우리 가족을 기억하는 AI"** — 상용 앱이 구조적으로 못 하는 것. 지난 대화("지난주에 캠핑
   간다고 했잖아, 어땠어?"), 각자의 관심사, 배운 표현을 기억하고 이어감. 학계가 지적한
   '맥락 인지 개인화 부재'를 정면으로 해결. 자가 호스팅이라 사생활 데이터가 집 밖에 안 나감.
2. **초등 3~5 사각지대 커버** — 아동 앱은 너무 얕고 성인 앱은 부적합한 정확히 그 지점.
   프로필별 수위·난이도 + 가족 단위 동기(가족 streak, 부모 리포트).
3. **가격** — 가족 3명이 스픽 프리미엄플러스를 쓰면 연 90만원. 우리는 연 0원.
4. **조용한 교정 + 확실한 복습 루프** — 대화 중엔 Recast로 흐름 유지, 뒤에서 기록,
   다음 대화에 재등장(간격 반복). "교정은 되는데 복습이 없다"는 업계 공통 약점 해결.
5. **호출어 핸즈프리** — 조사한 10개 앱 중 스마트 스피커식 사용을 지원하는 앱 없음.

### MVP에서 테스트할 차별화 기능: "기억+재등장 루프"

- 내용: ① 세션마다 가족 구성원별 사실·관심사·배운 표현을 구조화 저장 ② 다음 세션 시작 시
  Claude 프롬프트에 주입 ③ 배운 표현을 1/3/7일 주기로 대화에 재등장
- **추가 비용: 0원** (프롬프트+SQLite로 구현, 구독 한도 내)
- 효과 측정(MVP부터): 재등장한 표현을 사용자가 올바르게 쓰는 비율(습득률), 주간 세션 수·평균
  대화 길이(동기 유지) — 리포트 화면에 지표 노출

## 5. 구독료 가상 책정과 기회비용

**남에게 파는 서비스로 만든다면** (참고용): 자가 호스팅 음성 스택은 상품화 시 클라우드로 옮겨야
하고, 이때 사용자당 원가는 월 5천~1.5만원(LLM+STT+TTS). 최소 월 1.5~2만원은 받아야 하므로
스픽(월 환산 1.1~2.5만원)과 정면 경쟁 — 가격으론 못 이기고 "가족 공유 + 기억 개인화"로
승부해야 함. 상품화는 현 시점 권장하지 않음.

**가족용 자가구축의 기회비용 계산** (이게 실제 의사결정):

| | 상용 앱 (가족 3인) | 자가구축 |
|---|---|---|
| 연간 비용 | 스픽 기준 39~90만원, TalkPal 기준 24~40만원 | 0원 + 전기료 ~2만원 |
| 초기 투입 | 0 | 개발 4~5주(취미 시간) + 서버 셋업 반나절 |
| 아이 적합성 | 사각지대 | 프로필별 맞춤 |
| 기억/개인화 | 불가 | 핵심 기능 |
| 리스크 | 구독 해지하면 끝 | 구독 정책 변경 시 API 전환(월 ~1만원) |

손익분기: 개발 시간을 비용으로 안 치면 첫 해부터 이득. 시간을 치더라도 가족 2인 이상이
1년 이상 쓰면 상용 구독 대비 이득 + 상용 앱이 못 주는 기억·개인화·아동 맞춤을 얻음.

## 6. 결론 — MVP에 반영할 것

1. 교정 표시 UI 업계 표준 패턴(✓/✎ 아이콘 + 취소선/굵게 + 탭 설명) 채택
2. 프롬프트에 "AI가 의견을 먼저 내는" 규칙 추가 (TalkPal 반면교사)
3. DB 스키마에 처음부터 `family_facts`(기억)·`learned_items`(재등장 큐) 포함 — 차별화 기능의 기반
4. 발음 점수 기능은 넣지 않음 — 업계 전반이 부정확하다고 검증된 영역. 대신 "따라 말해보기"만
5. 게이미피케이션은 streak + 발화량만
6. 리포트에 습득률 지표(재등장 표현 정답률) — 차별화 기능의 효과를 데이터로 확인
